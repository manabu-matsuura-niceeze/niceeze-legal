**ニュースクローラー実装仕様:**
- 8カテゴリ: ビジネス/テクノロジー/ライフスタイル/食品/健康/EC/マーケティング/不動産
- Google News RSS（認証不要・無料・urllib標準ライブラリのみ）
- ネットワーク障害時はモックデータで自動フォールバック
- article_id: SHA-256ハッシュ（md5を廃止 — bandit B324対応）

**4フォーマット自動生成仕様:**
- X投稿: 140文字制限 + 4ハッシュタグ、トレンドスコア連動絵文字
- メルマガHTML: NiceEzeブランドカラー完全テンプレート、¥0コスト
- Note原稿: Markdown形式、手動投稿用（G4以降自動投稿 — 判断①C確定）
- YouTube台本: タイトル/説明文/台本、手動アップロード（判断②B確定）

**スケジューラー仕様:**
- Cloud Functions HTTP trigger エントリポイント: `run_schedule()`
- 朝8:00 JST = UTC 23:00 (`cron "0 23 * * *"`)
- 夜19:00 JST = UTC 10:00 (`cron "0 10 * * *"`)
- run_typeを自動判定（時刻ベース）またはリクエストパラメータで上書き可能
- G3実装時: Cloud Run proxy経由でClaude API品質向上（月額¥2,250〜¥4,500）
