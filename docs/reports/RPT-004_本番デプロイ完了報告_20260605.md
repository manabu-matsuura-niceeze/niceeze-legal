## 3. GCP Cloud Run 実デプロイ手順（松浦CEO実行）

以下のコマンドを GCP Cloud Shell または ローカルgcloud CLIで実行：

```bash
# 1. GCPプロジェクト設定
gcloud config set project YOUR_GCP_PROJECT_ID

# 2. Docker イメージビルド・push
docker build -f docker/research.Dockerfile -t gcr.io/YOUR_PROJECT/niceeze-research:latest .
docker build -f docker/marketing.Dockerfile -t gcr.io/YOUR_PROJECT/niceeze-marketing:latest .
docker push gcr.io/YOUR_PROJECT/niceeze-research:latest
docker push gcr.io/YOUR_PROJECT/niceeze-marketing:latest

# 3. Cloud Run デプロイ
gcloud run deploy niceeze-research \
  --image gcr.io/YOUR_PROJECT/niceeze-research:latest \
  --region asia-northeast1 \
  --platform managed \
  --allow-unauthenticated \
  --set-env-vars NICEEZE_ENV=production,GCP_PROJECT_ID=YOUR_PROJECT

gcloud run deploy niceeze-marketing \
  --image gcr.io/YOUR_PROJECT/niceeze-marketing:latest \
  --region asia-northeast1 \
  --platform managed \
  --allow-unauthenticated \
  --set-env-vars NICEEZE_ENV=production,GCP_PROJECT_ID=YOUR_PROJECT
```
