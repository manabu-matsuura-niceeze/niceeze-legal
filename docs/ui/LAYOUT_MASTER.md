### 1-2. グローバルレイアウト規則

- コンテナ: 固定グリッド（PC/スマホ共通固定レイアウト）
- レスポンシブ: PC優先、スマホはPWA/LIFF最適化
- カラーパレット: 成功=緑、警告=オレンジ、危険=赤（変更禁止）
- アニメーション: `popupIn`（スケール）を成約モーダルに固定
- ロックUI: `plan-locked` クラス = `opacity:0.45`, `grayscale(0.4)`, `pointer-events:none`

## 4. レイアウト変更承認フロー

```
変更要求発生
    ↓
CEO（松浦 学）へ変更内容を文書で提出
    ↓
CEO明示的承認
    ↓
LAYOUT_MASTER.md を先に更新（このファイル）
    ↓
実装コード変更
    ↓
layout-guard CI 自動検証
    ↓
Green → マージ許可
```

**承認なしのレイアウト変更 = layout-guard により自動却下（ビルド失敗）**
